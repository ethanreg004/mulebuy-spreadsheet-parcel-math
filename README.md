# Mulebuy Spreadsheet resource site

Mulebuy Spreadsheet parcel math notes: dimensional-weight estimates with dated inputs and divisors.

Live site: https://ethanreg004.github.io/mulebuy-spreadsheet-parcel-math/

This repository publishes a four-page independent resource site (Home, FAQ, Usage Guide, Alternatives). It records observations and checklists only; current prices, stock, inspection outcomes, and platform policies stay on the live platform pages.

## Pages

- `index.html` — overview and primary resource link
- `faq.html` — task-specific FAQ
- `usage-guide.html` — the four-step method
- `alternatives.html` — task-specific routing to other brand resources

## Update flow

Edit the HTML files and push to `main`; GitHub Pages serves the latest commit.
